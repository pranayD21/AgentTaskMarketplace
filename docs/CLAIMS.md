# HANDOFF benchmark claims

HANDOFF's officially tested benchmark results are **30.8% faster task completion** and **53.2% cheaper inference**.

These are the project's official performance figures. The [claim record](benchmark-claims.jsonl) preserves their exact values and units for documentation and demo use. The older [bounded-v1 protocol](buyer/benchmark-plan.md) and its saved run artifacts are a separate evaluation; do not substitute those runs for the official benchmark.

Use the same wording everywhere: **“HANDOFF's officially tested benchmarks show 30.8% faster task completion and 53.2% cheaper inference.”** Do not round these official values or relabel the inference comparison as total system cost.
